# Breakthrough Autoresearch Eval Rubric

## The skill passes when it:

- triggers for deep research, root-cause investigation, ranked hypotheses, autoresearch loops, or relentless metric-driven improvement work
- does not trigger for trivial fixes, docs-only tasks, or final production hardening after the direction is chosen
- grounds its analysis in repository evidence before outside comparison
- separates facts, inferences, and hypotheses
- produces a ranked backlog of falsifiable experiments
- uses keep/discard decisions grounded in metrics and noise
- includes stop conditions instead of open-ended thrashing
- hands off to `applied-ai-engineer` when the work becomes production hardening

## The skill fails when it:

- gives generic advice without repo grounding
- treats outside-company practices as universal truths
- runs experiments without a stable baseline
- accepts below-noise deltas as wins
- bundles many variables into one experiment by default
- keeps pushing the loop when the bottleneck has been disproven or the task should move to hardening
