# Phase 2 — Core, local protocol, and compatibility contracts

## Objective

Define the contracts before implementing the broker or extension. The local protocol and `agentyc-core` are canonical; the CLI/SDK and MCP adapter serialize them. No contract may expose raw Chrome tab IDs, CDP target/session IDs, or `[id] name` presentation.

## Current MCP boundary

The direct-CDP MCP server, its 61/76-tool profiles, and HTTP transport were removed after this plan was completed. The old MCP profiles and HTTP fixtures below are archived Phase 2 evidence only; they are not current routes, support claims, or release requirements. Current MCP is host-backed logical stdio only; its offline server lists 29 routes, its connected catalog declares 30 (11 return `capability_unavailable`), and only a limited existing-profile fence/rebind run has passed; full live validation remains open. See [`docs/mcp-compatibility.md`](../../../../mcp-compatibility.md).

## Handoff in

- **Inputs:** Phase 1 architecture/invariants; Phase 0 capability and budget addendum; D-09–D-17.
- **Must already be true:** browser boundary, profile guarantees, user-control states, and host ownership are closed.
- **Do not reopen:** local host/extension is primary; MCP adapter-only; no automatic Chrome launch/download; task spaces/pages are canonical.

## Confirmed facts

- At Phase 2 planning time, MCP schemas and errors lived in a direct-CDP server. That implementation was later removed; current logical routes are in `crates/agentyc-mcp/src/host_server.rs` and `remote_host_server.rs`.
- Existing CLI output is ad hoc JSON and current `run` closes the runtime per command.
- Native Messaging and local IPC have different framing/limits; the bridge must not conflate them.
- SDK/client connections need out-of-order response matching, cancellation, reconnect, and event resume.

## Working assumptions

- Use opaque prefixed IDs generated by the host; IDs are not target IDs and are not user-editable locators.
- Use versioned JSON envelopes over a 4-byte big-endian length-delimited local protocol; Native Messaging uses Chrome's platform framing at the bridge boundary.
- Keep payloads bounded; large artifacts use handles/chunks.
- Node SDK types can be generated/manual from JSON schema without owning browser logic.

## Local protocol

```json
{
  "protocol": 1,
  "kind": "request",
  "request_id": "req_...",
  "method": "page.snapshot",
  "params": { "space_id": "space_...", "page_id": "page_...", "mode": "min" },
  "deadline_ms": 30000,
  "idempotency_key": null
}
```

Responses are matched by `request_id` and may arrive out of order:

```json
{
  "protocol": 1,
  "kind": "response",
  "request_id": "req_...",
  "ok": true,
  "result": {},
  "error": null,
  "warnings": []
}
```

Events are broker-sequenced and scope-filtered:

```json
{
  "protocol": 1,
  "kind": "event",
  "event_id": "evt_...",
  "event": "page.changed",
  "broker_epoch": "epoch_...",
  "sequence": 42,
  "scope": { "space_id": "space_...", "page_id": "page_..." },
  "generation": {},
  "dirty_reason": "dom_mutation",
  "coalesced": true,
  "resync_required": false,
  "payload": {}
}
```

Delta contracts are normative: canonical UTF-8 JSON ordering, a declared hash algorithm, bounded patch operations (`upsert`, `remove`, `move`, `replace`, `frame_reset`), deterministic operation order, duplicate handling, bounded chain depth/count, and full/min fallback when the base is invalid or measured cost is higher. Multi-frame snapshots carry a version vector and are either coherent or explicitly partial; partial snapshots cannot issue refs.

Required error codes include `extension_not_connected`, `profile_not_found`, `space_required`, `space_not_found`, `space_forbidden`, `user_control_required`, `lease_expired`, `stale_lease`, `page_not_found`, `page_not_owned`, `unmanaged_page`, `stale_ref`, `target_replaced`, `event_lagged`, `unknown_outcome`, `reconciliation_required`, `capability_unavailable`, `permission_denied`, `native_host_unavailable`, `protocol_mismatch`, `message_too_large`, `invalid_argument`, `timeout`, `cancelled`, `host_draining`, and `ledger_incompatible`.
