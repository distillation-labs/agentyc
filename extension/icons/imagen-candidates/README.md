# Imagen icon candidates

Six monochrome browser-control candidates generated with Imagen and cropped
into Chrome-ready renders. Each directory contains the original 1024px render
plus transparent-corner 1024px, 128px, 48px, and 16px assets.

| Candidate | Direction |
| --- | --- |
| `01-solid-frame` | Solid browser frame with an oversized cursor |
| `02-action-rays` | Compact browser with cursor action rays |
| `03-open-frame` | Open frame with cursor and action rays |
| `04-outline-rays` | Outline frame with a larger cursor and rays |
| `05-clean-outline` | Minimal outline frame with a strong cursor |
| `06-inset-frame` | Inset browser frame with a clean cursor |

These are review assets only. `manifest.json` still references the current
production icon until one candidate is selected.
