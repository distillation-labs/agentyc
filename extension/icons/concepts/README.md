# Icon concepts

These nine wordless candidates are exploratory assets and are not referenced by
the production manifest. The filenames match the contact-sheet grid:

| Row | A | B | C |
| --- | --- | --- | --- |
| 1 | `a1-agent-loop` | `a2-path-monogram` | `a3-ring-signal` |
| 2 | `b1-quiet-spark` | `b2-signal-spark` | `b3-bright-spark` |
| 3 | `c1-cursor-trail` | `c2-browser-control` | `c3-cursor-ring` |

Each candidate has an editable SVG master and 16px, 48px, and 128px PNG
renders. The production `manifest.json` continues to point at
`../icon-{16,48,128}.png` until a direction is selected.
